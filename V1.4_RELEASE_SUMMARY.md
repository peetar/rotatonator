## 🎯 Key Features Explained

### DDR Silly Mode (New)
**What**: Optional background music and sound effects  
**Why**: Let users choose between professional visualization (default) or fun mode  
**Default**: OFF (for professional use out-of-box)

### In-Progress Heal Lane (New)
**What**: Shows heals descending toward their targets  
**Why**: Better visibility of what's happening in real-time  
**Features**: Target names, cyan target line, 10-second descent timing

### Score Export (New)
**What**: Copy scores to clipboard in `/rs` format  
**Why**: Easy sharing with raid group  
**Format**: `/rs HealerName: Score, HealerName: Score, ...`

### Overlay Resizing (New)
**What**: Drag corner to size overlay dynamically  
**Why**: Adapt overlay to different screen sizes  
**How**: Grab bottom-right corner, drag to desired size
