## Goals (Why)
- Make DDR mode a useful visualization tool for heal chains (not just silly/gimmicky)
- Improve configurability and UX of overlay system
- Allow users to choose between classic and DDR visualization modes
- Make the "silly" aspects (music, sound effects) optional rather than core to DDR mode

## Non-Goals (Out of Scope)
- Overhauling the core rotation logic
- Major refactoring of existing services
- New visualization modes beyond DDR/Classic
