- [x] **Hardened Append Macro Token Parsing**
  - Simple direct match on unique `rotat:` string (no need for lookbehind)
  - Allows optional whitespace after comma with `\s*` for flexibility
  - Simplified target pattern `\S+` for any non-whitespace target

- [x] **Updated README**: Added append macro feature documentation and usage examples
- [x] **Fixed Prefix Regex Bug**: Changed to accept bugged prefix formats
  - Legacy regex was strict on `ChainPrefix` config value
  - New regex accepts `D[& ]+D` (any spaces or ampersands between Ds)
  - Handles game bug where `D&D` sometimes appears as `D D` in logs

## Decisions & Notes

### Append Macro Design Decisions
- **Flexible whitespace**: Allows optional whitespace after comma (`rotat:3, %t` or `rotat:3,%t`)
- **Inline or standalone**: Scans every log line, works appended to macros or as standalone line
- **Position-based**: Number maps to healer position in chain (1-based)
- **Target flexibility**: Accepts any non-whitespace target string

### Regex Hardening Rationale
- **Direct pattern match**: `rotat:` is unique enough, no need for boundary checks
- **Optional whitespace `\s*`**: Allows space after comma for readability
- **Target pattern `\S+`**: Matches any non-whitespace characters (simpler than character class)
- **Prefix tolerance**: Handles EQ log bug where `D&D` appears as `D D` or `D  D`

### Buffering Design
- **Circular buffer**: Max 1000 lines to prevent memory growth
- **Timestamp preservation**: Stores both log timestamp and line content
- **Future-ready**: Enables duplicate detection, rate limiting, debugging features
